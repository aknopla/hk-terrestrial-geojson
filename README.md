# hk-terrestrial-geojson

Hong Kong's land area as a single GeoJSON MultiPolygon, kept up to date with
land the government's published coastline does not show yet.

## What "terrestrial" means here

Terrestrial means **land**: everything inside Hong Kong's coastline,
including the mainland (Kowloon and the New Territories), Hong Kong Island,
Lantau and the outlying islands. The sea is excluded.

Inland water, such as reservoirs, rivers and fish ponds, counts as land. The
polygons have no holes, so a point in the middle of a reservoir is inside the
area. That is the shape you want for "is this place on land in Hong Kong?":
masking the sea on a map, testing whether a coordinate is on land, or clipping
other data to the territory.

This is the land area only, not Hong Kong's jurisdictional boundary, which
also takes in surrounding waters.

## Files

| File | What it is |
|---|---|
| `hk_terrestrial.geojson` | **The dataset.** One feature: a MultiPolygon of 190 non-overlapping polygons, about 1,106.6 km². Minified, 375 KB. Generated by `merge.py`; don't edit it by hand. |
| `cedd_coastline.geojson` | The source: CEDD's 1:100,000 coastline, unmodified, as downloaded from CSDI on 2026-10-04. 193 polygons, about 1,090.0 km². |
| `additions.geojson` | Land missing from the source, drawn by hand: 15 polygons, one per line. Edit this file to add more land. |
| `merge.py` | Builds the dataset from the source and the additions. |

All files use WGS 84 longitude/latitude (`EPSG:4326` / `CRS84`), the
GeoJSON default. The dataset rounds coordinates to 7 decimal places, which
is about 1 cm.

## Why this exists instead of the government data

The government's coastline does not keep up with reclamation. CEDD's metadata
dates the 1:100,000 map's creation and last revision to 2000, so it shows
Hong Kong's land as of about then. Land reclaimed since is missing, even
though it is plainly part of Hong Kong. The largest gap is **Hong Kong
International Airport's Third Runway**: about 6.5 km² of reclaimed land.

This repo adds that land back, so anyone who needs "where is the land in Hong
Kong today" does not have to redraw it.

The dataset is also easier to use than the source:

- **Valid, one shape, no overlaps.** The source has 14 invalid polygons,
  mostly rings that cross themselves. The dataset repairs them and merges
  everything into a single valid MultiPolygon, so nothing is counted twice.
  That matters if you use the polygons as holes in a mask.
- **Small.** 375 KB, which suits bundling in an app.

## Rebuilding

```bash
pip install 'shapely>=2.1'
python merge.py
```

`merge.py`:

1. repairs every polygon in both inputs;
2. combines them into one shape, which removes all overlaps;
3. closes gaps under about 6 m wide where an addition meets the coastline,
   so the join doesn't show as a seam (only near additions, so the real
   coastline keeps its narrow inlets);
4. fills any holes and drops slivers under 10 m², all of them gaps left by
   the joins;
5. rounds coordinates to about 1 cm and writes `hk_terrestrial.geojson`.

## Source

The source is the `Coastline` layer of **Geological Maps in 1:100,000**,
published by the Civil Engineering and Development Department (CEDD),
Government of the Hong Kong SAR:

- [DATA.GOV.HK listing](https://data.gov.hk/en-data/dataset/hk-cedd-csu-cedd-geom-100k)
- CSDI portal dataset `cedd_rcd_1636520962284_7237`
  ([metadata](https://portal.csdi.gov.hk/geoportal/rest/metadata/item/cedd_rcd_1636520962284_7237))
- GeoJSON download:
  `https://portal.csdi.gov.hk/csdi-webpage/file-api?dataset_id=cedd_rcd_1636520962284_7237&format=geojson&layer_name=Coastline`

CSDI has moved download URLs before. If that link stops working, the
dataset ID and the metadata record will lead to the current one.

The source was drawn at 1:100,000, so expect the coastline to be off by tens
of metres in places. That's fine for a map overlay or a land/sea check, but
not for surveying.
